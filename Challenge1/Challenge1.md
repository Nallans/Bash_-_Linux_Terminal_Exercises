# A challenge for you

Without changing directories manually multiple times, create this structure in one command:

project/
├── src/
│   ├── main.c
│   └── utils.c
├── include/
│   └── utils.h
├── docs/
│   ├── README.md
│   └── notes.txt
└── tests/

In other words: create the directories and all six files with a single Bash command.
