# Exercise 28 — Your first variable

Create a variable called name and give it your name.

Then:

Display the variable.
Create another variable containing a number.
Display both variables in one sentence.
Change the value of the variable.
Display it again.

You'll need to discover how Bash assigns and expands variables.

Important

Pay attention to the difference between:

name=value

and:

name = value

Bash does not interpret those the same way.
