# Exercise 30 — Command substitution

You've already used commands whose output becomes input to another command.

Now we're going to put the output of a command inside a variable.

For example, conceptually:

variable=$(some_command)

Your tasks:

Store the output of pwd in a variable.
Display the variable.
Store the current date in a variable.
Display it.
Store the number of files in your project in a variable.
Display a sentence containing that number.

You'll discover:

$(...)

This is called command substitution.
